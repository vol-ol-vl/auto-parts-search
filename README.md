# Поиск автозапчастей

React-приложение для поиска автозапчастей и подбора аналогов с использованием API Favorit Parts.

## Возможности

- Поиск производителей детали по артикулу.
- Выбор производителя из полученного списка.
- Поиск аналогов выбранной детали.
- Отображение информации о деталях: артикул, наименование и производитель.
- Просмотр предложений по складам с ценами и остатками.
- Обработка состояний загрузки, ошибок API и сети, а также пустых результатов.

## Технологии

- React
- JavaScript
- Redux Toolkit
- RTK Query
- React Redux
- Bootstrap
- Vite

## Реализовано

- Работа с REST API Favorit Parts.
- Управление состоянием приложения с помощью Redux Toolkit.
- Получение и обработка данных через RTK Query.
- Обновление данных после выполнения запросов на основе механизма тегов RTK Query.
- Обработка асинхронных состояний и ошибок запросов.

## Запуск проекта

Клонировать репозиторий:

```bash
git clone https://github.com/vol-ol-vl/auto-parts-search.git
```

Перейти в папку проекта:

```bash
cd auto-parts-search
```

Установить зависимости:

```bash
npm install
```

Запустить локальный сервер:

```bash
npm run dev
```

Production-сборка:

```bash
npm run build
```

Проверка кода ESLint:

```bash
npm run lint
```

## API

Для получения информации об автозапчастях и предложениях поставщиков используется API Favorit Parts.
